# web-dev-applications

Small front-end and Node.js projects built while learning web development, roughly in the order they were made.

| # | Project | Stack |
|---|---------|-------|
| 1 | [HTML-CSS](1.HTML-CSS) | Static personal site with HTML and CSS |
| 2 | [Calculator using node and express](2.%20Calculator%20using%20node%20and%20express) | Express server with a BMI calculator |
| 3 | [Dicee Challenge](3.%20Dicee%20Challenge%20-%20Starting%20Files) | DOM manipulation, random dice game |
| 4 | [Simon Game](4.%20Simon%20Game%20Challenge%20Starting%20Files) | jQuery, sound and animation |
| 5 | [Drum Kit](5.Drum%20Kit%20Starting%20Files) | Keyboard and click events, audio |
| 6 | [intro-to-node](6.intro-to-node) | Node.js basics and npm modules |
| 7 | [express-app](7.express-app) | First Express routes |
| 8 | [calculator-express](8.calculator-express) | Handling form POSTs with Express |
| 9 | [WeatherProject](9.WeatherProject) | Express + OpenWeather API over HTTPS |
| 10 | [Newsletter-Signup](10.Newsletter-Signup) | Express + Mailchimp API (credentials via env vars, see `.env.example`) |
| 11 | [EJSTodoList](11.EJSTodoList) | Server-side rendering with EJS templates |

## Running a Node project

```sh
cd "<project folder>"
npm install
node app.js   # or server.js / index.js, depending on the project
```
